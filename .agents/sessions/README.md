# Sessions

This directory is the chronological conversation journal.

## Naming

Use one file per date:

```text
YYYY-MM-DD.md
```

Multiple conversations on the same date should be appended as separate headings in the same file.

## Entry template

```md
## HH:MM — Short label

- User wanted: ...
- Actions/decisions: ...
- Durable updates: ...
- Open loop: ...
```

Use a local timestamp when it is reliably available; otherwise use a clear sequence label.

Keep entries concise. They are summaries, not transcripts.
